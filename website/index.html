Manifesto

Agents should show their work. Observations stay observations. Unknowns stay unknowns. Budgets stay visible.

reaharness is a thin harness, not a framework cult. Typed tools over MCP and CLI. A provider loop that speaks OpenAI-compat and Anthropic. Setup that prints a plan before it touches your config.

Tools return proof, not vibes.

Every result carries observations, unknowns, and budgets. Missing coverage stays unknown.

Agent loop

Model, tools, evidence, repeat.

The same harness tools MCP exposes. Bounded turns. Structured tool results back into the transcript.

  • Max-turn stop with a clear reason
  • Workspace session memory under .reaharness/
  • Architecture guard keeps layers honest
$ reaharness agent \
  --provider=anthropic \
  "Summarize this repo"
